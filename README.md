# Workout Tracker

Workout Tracker is a full-stack web application for logging and tracking gym workouts. Users can build a personal workout history by selecting exercises from a predefined exercise catalogue, recording sets, reps, and weight, and monitoring their progress over time.

The project is currently focused on building a robust backend with a REST API, authentication, and comprehensive test coverage. A frontend client will be added in a future phase.

## Tech Stack

- **Backend:** [Node.js](https://nodejs.org/en), [Express](https://expressjs.com/), [TypeScript](https://www.typescriptlang.org/)
- **Database:** [PostgreSQL](https://www.postgresql.org/), [Drizzle ORM](https://orm.drizzle.team/)
- **Authentication:** [JSON Web Token (JWT)](https://jwt.io/), [bcrypt](https://www.npmjs.com/package/bcryptjs)
- **Testing:** [Vitest](https://vitest.dev/)
- **Code Quality:** [Prettier](https://prettier.io/), [ESLint](https://eslint.org/), [Husky](https://typicode.github.io/husky/), [lint-staged](https://github.com/lint-staged/lint-staged)

## Prerequisites

- Node.js >= 24
- npm
- PostgreSQL

## Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Harsh3006/workout-tracker.git
   cd workout-tracker
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Configure the environment**

   ```bash
   cp .env.template .env
   ```

   Update the required environment variables in `.env`.

4. **Run the database migrations**

   ```bash
   npx drizzle-kit migrate
   ```

5. **Seed the exercise catalogue**

   ```bash
   npm run seed
   ```
